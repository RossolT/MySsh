# MySsh

Настольный SSH- и SFTP-клиент для Windows на базе **.NET 10** и **WinForms**. Объединяет встроенный терминал, двухпанельный SFTP-менеджер, редактор удалённых файлов с подсветкой синтаксиса и безопасное управление профилями подключений.

---

## Основные возможности

* **Управление подключениями:**
  * Создание, редактирование, удаление и быстрый запуск сохранённых профилей (`SSH` и `SFTP`).
  * Шифрование паролей в локальном хранилище с помощью Windows DPAPI (`SecretProtector`).
  * Запрос пароля при подключении, если он не сохранён в профиле или перенесён с другого ПК.
* **Экспорт и импорт профилей:**
  * Выгрузка и загрузка списка подключений в формате JSON.
  * Защита кнопки **«Экспорт»** подтверждением личности через **Windows Hello** (PIN-код или биометрия), если функция настроена в системе.
* **SSH-терминал:**
  * Встроенный терминал на базе **WebView2** и **xterm.js** поверх **SSH.NET**.
  * Поддержка многовкладочного интерфейса в единой цветовой теме приложения.
* **SFTP-клиент и редактор файлов:**
  * Просмотр и управление локальными и удалёнными директориями.
  * Встроенный текстовый редактор на базе `FastColoredTextBox` со светлой темой и подсветкой синтаксиса для **JSON**, конфигурационных файлов (`.ini`, `.conf`, `.env`) и **shell-скриптов** (`.sh`).

## Технологический стек

* **Платформа:** .NET 10 (`net10.0-windows10.0.26100.0`), WinForms
* **SSH / SFTP:** `SSH.NET`
* **Эмулятор терминала:** `Microsoft.Web.WebView2` + `xterm.js`
* **Редактор кода и конфигов:** `FastColoredTextBox.NET10`
* **Аутентификация при экспорте:** WinRT `Windows.Security.Credentials.UI.UserConsentVerifier` (Windows Hello)

## Требования для запуска и сборки

### Для разработки
* **Visual Studio 2022 / 2026** или **.NET 10 SDK**
* **Windows 10 / 11 SDK** (версия `10.0.26100.0` или совместимая) для работы API Windows Hello

### Для запуска на целевом ПК
* **Windows 10 / 11 (x64)**
* **Microsoft Edge WebView2 Runtime** (предустановлен в современных версиях Windows 10/11)
* **.NET 10 Desktop Runtime** (если приложение опубликовано в режиме *framework-dependent*; при *self-contained* установке не требуется)

## Сборка и публикация

### Сборка через .NET CLI
```bash
dotnet build MySsh.csproj -c Release
```

### Публикация автономной версии (Self-Contained, x64)
Создаёт папку со всеми необходимыми компонентами, которую можно перенести на другой ПК в виде архива:

```bash
dotnet publish MySsh.csproj -c Release -r win-x64 --self-contained true -o ./publish/MySsh-win-x64
```

### Публикация компактной версии (Framework-Dependent)
Подходит для ПК, где уже установлен **.NET 10 Desktop Runtime**:

```bash
dotnet publish MySsh.csproj -c Release -r win-x64 --self-contained false -o ./publish/MySsh-fdd
```

## Примечания по безопасности и переносу данных

* Пароли профилей защищаются средствами **Windows DPAPI** с привязкой к текущему пользователю Windows.
* При переносе экспортированного JSON-файла на другой компьютер или под другую учётную запись Windows зашифрованные пароли не расшифруются автоматически — при первом подключении приложение запросит пароль вручную.
* Если на компьютере настроен PIN или биометрия **Windows Hello**, перед экспортом профилей запрашивается подтверждение личности. Если Windows Hello в системе не активирован, экспорт выполняется без системного запроса.
